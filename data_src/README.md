# data_src — 사람이 손으로 쓴 데이터

여기 있는 것만 git 에 올린다. 생성 데이터(`data/`)는 올리지 않고 명령으로 다시 만든다.
쓰는 법은 [F9 학습 가이드](../docs/F9_학습_가이드.md) 7-5 · 7-6 에 있다.

| 폴더 | 무엇 | 쓰임 | 검사 |
|---|---|---|---|
| `real/<이름>.tsv` | 실제 문장 (id · 기준시각 · 문장 · 정답 · 메모) | **시험 문제** — 학습에 넣지 않는다 | `python src/make_real.py --check` |
| `frames/<이름>.tsv` | 말투 틀 (id · 종류 · 틀 · 메모) | 학습 데이터 v3 의 재료 | `python src/prepare_f9_v3.py --check` |
| `examples/` | 예시 파일 — 형식을 볼 때만 쓴다 | 시험·학습에 들어가지 않는다 | 위 명령 뒤에 파일 경로를 붙인다 |

- 자기 파일만 고친다. 칸 사이는 **탭**이다(구글 시트에 쓰고 행을 복사해 붙이면 된다).
- 실제 사람 이름·학번·연락처는 쓰지 않는다. 이 저장소는 공개다.
- 검수용 표: `python src/make_real.py --show` · `python src/prepare_f9_v3.py --show`
