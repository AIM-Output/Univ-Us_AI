## 결과 (`eval.jsonl` 358턴)

| | 턴 정확도 | 도구 선택 | 인자 일치 | 필드 정확도 | 거절 정확도 |
|---|---:|---:|---:|---:|---:|
| **f9-r0** | **77.9** | 95.6 | 94.2 | 96.2 | 4.6 |
| AI 팀 1차 | 77.7 | 91.1 | 88.4 | 90.3 | 29.2 |
| 학습 전 — 우리 | 33.2 | 68.9 | 40.3 | 51.1 | 1.5 |
| 학습 전 — AI 팀 | 33.2 | 68.3 | 40.3 | 50.0 | 1.5 |

턴 정확도는 기준(77.7% ±2%p) 안입니다. **구성은 다릅니다.**

| 달라진 곳 | f9-r0 | AI 팀 1차 |
|---|---:|---:|
| 거절 (65턴) | 3턴 맞음 | 19턴 맞음 |
| `list_events` 도구 선택 (69턴) | 100% | 81.2% |
| `list_events` 인자 일치 | 97.1% | 79.7% |
| `create_event` 인자 일치 (46턴) | 95.7% | 87.0% |
| `update_event` 인자 일치 (19턴) | 100% | 94.7% |
| `open_placement` 도구 선택 (13턴) | 0% | 0% |

- 두 모델은 같은 약점을 다른 방향으로 틀립니다. AI 팀 모델은 거절을 더 자주 해서 맞는 거절이 많은 대신 `list_events` 를 13턴 놓쳤고, f9-r0 는 거의 거절하지 않아 도구 호출은 다 맞히고 거절을 틀립니다. 맞은 턴 수는 279 대 278 입니다.
- 거절과 `open_placement` 는 v1 데이터에 거의 없는 유형입니다. 나머지 8개 도구의 도구 선택은 양쪽 모두 100% 입니다.
- 이 차이가 `--low_vram` 의 어텐션 커널 때문인지, 환경 차이(Windows · torch 2.9)에서 오는 편차인지는 이 한 번으로는 가릴 수 없습니다.
