# 날짜 진단 — 정답 날짜가 말일·1일이면 약한가 (180문장)

f9-r1 이 eval 에서 틀린 날짜 2턴은 둘 다 정답이 10월 31일이었습니다. 우연인지 약점인지 보려고 만든 진단입니다.
**학습에는 넣지 않습니다.** 점수를 재는 데만 씁니다.

## 진단 문장

| 항목 | 값 |
|---|---|
| 만드는 법 | `python scripts/make_date_probe.py` → `outputs/date_probe/probe_dates.jsonl` (seed 20261123) |
| 지문 | 180행 · sha256 앞 12자리 `93ba6efce050` (`data_sha256.txt`). 2026-11-23(실제 문장 320개)과 11-27(380개)에 만든 파일이 같습니다 |
| 말투 | v2 생성기의 등록 틀(`CE_TIMED`) 그대로 — 말투는 학습 때 본 것이고 **날짜만 새로** 뽑았습니다 |
| 날짜 표현 | "N일 뒤"(2~14일) 90문장 · "다음 주 X요일" 90문장 |
| 묶음 | 정답 날짜가 떨어지는 곳 6가지. 31일은 표현마다 30문장, 나머지는 12문장씩 |
| 겹침 | 학습 문장 · eval · 실제 문장과 같은 문장은 없습니다 |

채점은 `eval.py` 로 합니다(명령은 `scripts/make_date_probe.py` 머리말). 결과는 `scripts/analyze_probe.py` · `scripts/compare_runs.py` 로 봅니다.

- 도구는 180문장 모두 맞게 골랐습니다. 틀리는 것은 날짜입니다.
- **틀리는 모양**: "N일 뒤" 는 말일을 건너뛰어 하루 뒤로(+1일), "다음 주 X요일" 은 한 주 뒤로(+7일) 답합니다.
- 달력에 없는 날짜도 3번 답했습니다(6월 31일 2번 · 7월 32일 1번).
- 오늘이 일요일일 때의 "다음 주 X요일" 은 6문장 중 1문장만 맞았습니다.
- 자세한 표와 틀린 문장은 `f9-r1/summary.txt` 에 있습니다.

**왜 약한가 (데이터)**: v1+v2 학습 데이터에서 계산이 필요한 날짜 문장 4,261행 가운데 정답이 말일·1일인 행은 382행(9%)입니다. v2 생성기가 기준시각을 1년에서 고르게 뽑기 때문입니다.
